# Ключевая эпоха

## Временной диапазон
**2000–2005 годы.**

## Почему выбран этот период
**2000**: выход Python 2.0 (16 октября) - версия, которая дала языку Unicode, новый сборщик мусора и открытый процесс разработки.
**2000–2001**: переход команды PythonLabs на SourceForge; создание Python Software Foundation (2001).
**2000–2005**: рост веб-разработки на Python (Zope, Mailman, CGI); первые массовые курсы и тренинги (PythonWare training в Швеции, 2000; Big Nerd Ranch Python Bootcamp, 2005).
Это период, когда Python перестал быть «языком для избранных» и стал инструментом, который можно продавать как навык.

## Технологическая среда
**Устройства**: настольные ПК (Pentium III/4), ноутбуки; мониторы 15–17 дюймов, разрешение 1024×768.
**Операционные системы**: Windows 2000, Windows XP (с 2001), Linux (Red Hat, Debian, Mandrake), Mac OS 9 / Mac OS X (с 2001).
**Способы подключения**: dial-up (56k), начинающийся широкополосный доступ (DSL, кабель).
**Носители**: CD-ROM, дискеты 3.5″, Zip-диски.
**Типичные программы**: Internet Explorer 5/6, Netscape, текстовые редакторы (Notepad, Emacs, Vim), CVS для контроля версий.
**Инструменты Python**: IDLE (в поставке), PythonWin, Emacs с python-mode, ActiveState Komodo (2000-е).

## Визуальный язык
**Типографика**: Tahoma, Verdana, MS Sans Serif; кегль 11–12 px; плотный, без больших отступов.
**Цвета**: серый фон (#C0C0C0, #D4D0C8), синие заголовки (#000080), белые поля ввода; акцентный синий (#0000FF) для ссылок.
**Рамки и кнопки**: 3D-эффект (outset/inset), серые панели с белыми и тёмно-серыми границами; кнопки с градиентом от светло-серого к серому.
**Композиция**: табличная вёрстка, плотные блоки текста, баннеры 468×60, счётчики посещений, «best viewed in Internet Explorer».
**Изображения**: скриншоты интерфейсов, пиксельные иконки, логотипы с заливкой.

## Рекламный язык
Обещания: «простой», «быстрый», «мощный», «батарейки в комплекте», «учись за выходные».
Интонация: уверенная, почти директивная; часто используется восклицание и заглавные буквы для акцентов.
Формулировки: «Python 2.0 - новый стандарт», «Начни программировать сегодня», «Курс для тех, кто хочет делать больше, а писать меньше».

## Культурный фон
Веб 1.0: статические сайты, гостевые книги, форумы.
Популярность Linux и open-source; культура «хакеров» и IRC.
Фильмы и игры начала 2000-х: «Матрица», «Властелин колец», Counter-Strike, The Sims.
Компьютерные журналы: «Мир ПК», «Компьютерра», «Хакер» - плотная вёрстка, много рекламы ПО и курсов.

## Границы стилизации
Разрушат образ:
скруглённые карточки с мягкими тенями (стиль 2010-х);
градиентные «пятна» и минимализм;
шрифты Helvetica Neue, Roboto, Inter;
большие пустые пространства;
анимации при скролле, parallax;
эмодзи вместо пиксельных иконок;
современные скриншоты IDE (тёмная тема, актуальная версия Python, интерфейс актуальной ОС) - они датируют страницу 2020-ми годами так же сильно, как круглая карточка с тенью.
