# Шапка (Hero)

## Назначение
Посетитель сразу понимает, что это за курсы, для кого они и какую эпоху представляет страница.

## Содержание
Логотип: пиксельный логотип Python (1990-е).
Заголовок: **PythonWare: язык для тех, кто хочет делать больше**
Подзаголовок: **Курсы Python 2.0. Меньше кода - больше результата.**
Строка с датой: *Python 2.0 вышел 16 октября 2000 года. Мы учим тому, что действительно работает.*
Кнопка: **Записаться на курс** (ведёт к блоку 06).

## Связь с объектом
Python 2.0 - ключевая версия, с которой началась массовость языка. Название курсов отсылает к реальному учебному центру PythonWare Training (Швеция, 2000).

## Связь с эпохой
Логотип - старый, пиксельный (до 2006 года). Шрифт - Tahoma. Цвета - серый фон, синий заголовок. Кнопка - 3D-стиль Windows.

## Визуальные ориентиры
era.md: серый фон #C0C0C0, синий #000080 для заголовков, Tahoma 12px. sources.md: старый логотип Python (Wikimedia Commons).
