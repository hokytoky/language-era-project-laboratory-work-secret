# Программа курса

## Назначение
Посетитель видит конкретную программу обучения, основанную на реальных возможностях Python 2.0.

## Содержание
Заголовок: **Программа курса «Python 2.0: от скрипта до приложения»**

Таблица (как в учебном расписании):

| Модуль | Тема | Результат |
|---|---|---|
| 1 | Синтаксис и типы данных | Пишете простые скрипты на Python |
| 2 | Работа с текстом и Unicode | Обрабатываете файлы и строки на любом языке |
| 3 | Модули и стандартная библиотека | Используете «батарейки в комплекте» |
| 4 | Сети и веб (CGI) | Создаёте динамические веб-страницы |
| 5 | Объектно-ориентированное программирование | Проектируете классы и модули |
| 6 | Работа с SourceForge | Участвуете в открытой разработке |

Подпись: *Каждый модуль - практика на реальных задачах. Никакой воды.*

## Связь с объектом
Модуль 2 (Unicode), модуль 3 («batteries included»), модуль 6 (SourceForge) - реальные особенности Python 2.0.

## Связь с эпохой
Таблица - типичный элемент веб-страниц 2000-х. Шрифт Tahoma, серые границы ячеек.

## Визуальные ориентиры
era.md: табличная вёрстка. sources.md: скриншот IDLE - редактор с подсветкой синтаксиса.
