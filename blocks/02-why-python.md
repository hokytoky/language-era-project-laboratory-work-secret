# Почему Python

## Назначение
Посетитель понимает три конкретных преимущества Python 2.0, которые делают его ценным инструментом в 2000–2005 годах.

## Содержание
Заголовок: **Почему Python 2.0 - это шаг вперёд**

Три пункта в табличной вёрстке (как в компьютерных журналах):
1. **Unicode** - Python 2.0 впервые поддерживает Unicode. Ваши программы работают с текстом на любом языке.
2. **Сборщик мусора с обнаружением циклов** - память освобождается автоматически, даже при циклических ссылках. Меньше утечек - больше времени на задачи.
3. **Открытая разработка на SourceForge** - исходный код, баг-трекер и патчи доступны всем. Сообщество растёт, язык развивается быстрее.

Подпись внизу: *Python 2.0 вышел 16 октября 2000 года. С тех пор язык стал стандартом для веб-скриптов, системного администрирования и обучения.*

## Связь с объектом
Все три факта подтверждены в research.md: Unicode, сборщик мусора, SourceForge - реальные особенности Python 2.0.
