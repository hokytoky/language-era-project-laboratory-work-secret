# Запись на курс

## Назначение
Посетитель понимает, как записаться, и видит конкретные детали (цена, дата, формат).

## Содержание
Заголовок: **Записаться на курс Python 2.0**

Текст:
> Ближайший поток: **март 2001 года**.
> Формат: 6 недель, два вечера в неделю.
> Стоимость: **$299** (включая доступ к SourceForge-репозиторию с примерами).
> Требования: базовое знание командной строки; опыт программирования на любом языке приветствуется, но не обязателен.

Кнопка: **Записаться сейчас** (имитация отправки формы; без реальной серверной обработки).

Подпись мелким шрифтом: *PythonWare Training не связан с Python Software Foundation. Python - торговая марка PSF. Курсы предназначены для образовательных целей.*

## Связь с объектом
SourceForge - реальная платформа, на которую перешла разработка Python в 2000 году. Стоимость $299 соответствует ценам тренингов начала 2000-х.

## Связь с эпохой
Форма записи с кнопкой - типичный элемент веб-страницы 2000-х. Дата «март 2001» - до создания PSF (2001), но в рамках выбранного периода.
