## Коротко о проекте
Одностраничный рекламный сайт вымышленного учебного центра «PythonWare», предлагающего курсы по Python в эпоху 2000–2005 годов. Страница стилизована под интерфейсы Windows 2000/XP и ранних веб-сайтов: серые панели, 3D-рамки, плотная типографика, язык обещаний «простоты» и «скорости разработки». В основе - реальная история Python 2.0: переход на SourceForge, поддержка Unicode, философия «батарейки в комплекте» и сообщество, которое сделало язык массовым.
