# Исследование Python

## Коротко
Python интерпретируемый язык программирования высокого уровня, созданный Гвидо ван Россумом. Его ценность в том, что он соединил читаемый синтаксис с практичностью: язык одинаково хорошо подходил для системного администрирования, веб-разработки, научных расчётов и обучения. В начале 2000-х Python стал массовым инструментом.

## Происхождение
Python задуман в конце 1980-х, реализация начата в декабре 1989 года Гвидо ван Россумом в CWI (Нидерланды) как наследник языка ABC. Первый публичный релиз (0.9.0) опубликован в феврале 1991 года в alt.sources. Название языка происходит от шоу «Monty Pythons Flying Circus», а не от змеи.

## Исходная проблема
ABC был мощным, но ограниченным: в нём не хватало обработки исключений и взаимодействия с операционной системой. Python создавался как язык, который сохранит читаемость ABC, но добавит практичности - работу с файлами, сетью, процессами.

## Пользователи и области применения
Системные администраторы Unix: сценарии автоматизации.
Веб-разработчики: CGI-скрипты, серверные приложения (Zope, Mailman).
Научные сотрудники и инженеры: расчёты, обработка данных.
Преподаватели: обучение программированию благодаря чистому синтаксису.

## Ключевые вехи
1. **1991** - публикация Python 0.9.0 в alt.sources.
2. **Январь 1994** - Python 1.0: появились lambda, map, filter, reduce.
3. **1994** - создан форум comp.lang.python, начало формирования сообщества.
4. **1995–1999** - работа над Python в CNRI (Reston, Вирджиния); выпуск версий 1.3–1.5.2.
5. **16 октября 2000** - Python 2.0: сборщик мусора с обнаружением циклов, поддержка Unicode, переход на SourceForge и открытый процесс разработки.
6. **2001** - создан Python Software Foundation (PSF).

## Важные платформы, продукты и проекты
**SourceForge** - платформа, на которую перешла разработка Python в 2000 году; сделала процесс прозрачным и общедоступным.
**Zope** - сервер приложений на Python; компания Digital Creations (позже Zope Corporation) приняла команду PythonLabs в 2000 году.
**Mailman** - система списков рассылки на Python, использовавшаяся в GNU-проектах.
**IDLE** - встроенная среда разработки, входившая в поставку Python с версии 1.5.2b1.

## Почему объект был ценен в выбранную эпоху (2000–2005)
В 2000–2005 годах Python 2.0 дал языку три ключевых преимущества: **Unicode**, **сборщик мусора** и **прозрачный процесс разработки**. Это совпало с ростом веба и потребностью в быстрой разработке. Python предлагал «батарейки в комплекте» - стандартную библиотеку, покрывавшую сеть, файлы, регулярные выражения и базы данных. В то же время синтаксис оставался настолько чистым, что язык стали использовать для обучения. Сообщество вокруг comp.lang.python и SourceForge превратило Python из личного проекта в коллективный инструмент.

## Факты для рекламной концепции
Название языка - отсылка к «Monty Python», а не к змее.
Девиз сообщества: «Batteries included» - богатая стандартная библиотека.
CP4E (Computer Programming for Everybody) - инициатива ван Россума при поддержке DARPA, целью которой было сделать программирование доступным.
Python 2.0 вышел 16 октября 2000 года - дата, которую можно использовать как точку отсчёта курсов.

## Что осталось спорным
Точная дата первого релиза: одни источники называют февраль 1991, другие - «early 1991». Формулировка «ранняя весна 1991» безопаснее.
