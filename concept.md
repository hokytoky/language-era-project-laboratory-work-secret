# Концепция

## Название вымышленных курсов
**PythonWare: язык для тех, кто хочет делать больше**

## Идея одним предложением
Учебный центр «PythonWare» продаёт курсы Python 2.0 как инструмент, который позволит программистам и администраторам писать меньше кода, но решать больше задач - от веб-скриптов до системной автоматизации.

## Кто предлагает обучение
Вымышленный учебный центр **PythonWare Training**, существующий при «секретной лаборатории» - отсылка к реальной компании Secret Labs AB (разработчик PythonWorks), которая предлагала тренинги по Python в Швеции в 2000 году.

## Аудитория
Системные администраторы Unix/Linux, уставшие от shell-скриптов.
Веб-разработчики, пишущие на Perl и ищущие более читаемую альтернативу.
Студенты и преподаватели, которым нужен язык для обучения программированию.
Инженеры и научные сотрудники, работающие с данными и расчётами.

## Главное обещание
**«Меньше кода - больше результата»**: Python 2.0 даёт Unicode, сборщик мусора и «батарейки в комплекте», чтобы вы писали программы быстрее и не тратили время на низкоуровневые детали.

## Голос рекламы
Уверенный, дружелюбный, с лёгкой иронией. Говорит как опытный программист, который уже пользуется Python и хочет поделиться инструментом. Без снобизма, но с ощущением «мы знаем, что делаем».

## Центральная шутка
Python назван в честь «Monty Python», а не змеи. Курсы могут использовать это: «Мы не про змей. Мы про язык, который кусается только тогда, когда вы пишете на Perl». Шутка работает, потому что она основана на реальном факте и понятна аудитории того времени.

## Что посетитель должен понять об объекте
1. Python - не игрушечный язык, а рабочий инструмент для реальных задач.
2. Python 2.0 (2000) - важная веха: Unicode, новый сборщик мусора, открытая разработка.
3. Язык ценен читаемым синтаксисом и богатой стандартной библиотекой.
4. Сообщество вокруг Python активно и открыто - это часть ценности языка.

## Что агент не должен потерять при сборке
Дату выхода Python 2.0 (16 октября 2000) и её значение.
Философию «batteries included».
Название языка как отсылку к «Monty Python».
Ощущение эпохи: Windows 2000/XP, SourceForge, плотная вёрстка.
