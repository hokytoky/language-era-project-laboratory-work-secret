# Источники

## История и факты
1. **History of Python** - https://en.wikipedia.org/wiki/History_of_Python
   Что проверено: дата начала реализации Python (декабрь 1989), CWI, ван Россум как основной автор, происхождение названия от Monty Python, дата Python 2.0 (16 октября 2000), ключевые особенности 2.0.

2. **History of Python - EPFL GraphSearch** - https://graphsearch.epfl.ch/en/concept/21356332
   Что проверено: хронология версий (0.9.0 в феврале 1991, 1.0 в январе 1994), создание comp.lang.python в 1994, особенности Python 1.0 (lambda, map, filter, reduce).

3. **The History of Python - Introduction (Guido van Rossum)** - https://gvanrossum.github.io/neopythonic/the-history-of-python-introduction.html
   Что проверено: личное свидетельство автора о начале работы в декабре 1989 года.

4. **Python Documentation: History and License** - https://docs.python.org/id/3.10/license.html
   Что проверено: переход в CNRI (1995), BeOpen (2000), Digital Creations/Zope (2000), создание PSF (2001).

5. **What's New in Python 2.0** - https://docs.python.org/ja/3.16/whatsnew/2.0.html
   Что проверено: дата релиза 2.0 (16 октября 2000), переход на SourceForge, новый процесс разработки, сборщик мусора, Unicode.

6. **ANN: Python training in Sweden! (2000)** - https://mail.python.org/archives/list/python-list@python.org/message/4X3AOAQ5DEMX2MHAHJ7HAVJT7M67GLZK/
   Что проверено: существование тренингов PythonWare в 2000 году; использовано как прототип вымышленного учебного центра. Это архивное сообщение от 23 января 2000 года, в котором Secret Labs AB (PythonWare) объявляет о начале тренингов в Швеции. Сама оригинальная ссылка на данный момент не функционирует из за ее срока давности; существование Secret Labs AB в те годы.

## Визуальные источники
1. **IDLE (Python) - Wayback Machine, 1998** - https://web.archive.org/web/19981222000000/http://www.python.org/idle/
   Что взято как ориентир: скриншот IDLE под Windows - текстовый редактор с подсветкой синтаксиса и интерактивная оболочка. Использован для стилизации блока «Программа курса».

2. **Старый логотип Python (1990-е–2006)** - https://ru.wikipedia.org/wiki/%D0%A4%D0%B0%D0%B9%D0%BB:Python_logo_1990s.svg
   Что взято как ориентир: пиксельный логотип Python с двумя змеиными головами. Использован в шапке страницы.
